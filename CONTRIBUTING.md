# Contributions

Contributing to the theme is always welcome and pull requests will be reviewed shortly after submission. Generally, you should...

  - Keep the code clean. Make sure your code fits in the respective file. Make sure to format all changes using Prettier and ensure you are using the repository's prettierrc file.
  - Do not add brand new SCSS files without previous discussion. Try to fit in existing css files
  - Do not radically modify the design of the theme (like making the sidebar separate, adding a solid background to posts, etc). Small tweaks and enhancements are welcome, but your PR will be denied if it modifies the design too much.
  - Do not add imports or requests to your own self-hosted service or a smaller one that I don't instantly know. Avoid 3rd-party requests entirely if possible but they should be used in moderation.
  - Don't add anything too complex or unmaintainable.
